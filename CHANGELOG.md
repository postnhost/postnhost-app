# Changelog

All notable changes to PostnHost App are documented in this file.

## [0.1.1] - 2026-08-31

First open source release of PostnHost App.

### Added

- PostnHost engine 0.1.1 with the complete publishing and administration experience.
- Rails 8.1 application with SQLite, Solid Queue, Solid Cache, and Solid Cable.
- Litestream backups and deployment configuration for Docker and Fly.io.
- Host-side Tailwind build for safely customizing copied PostnHost templates.
- Example public template customization inspired by an editorial blog layout.
- Integration and browser smoke tests for setup, authentication, and publishing.
